# Codex Task Prompts

## Plan a Feature

Use `PLANS.md` and document goal, scope, non-goals, data/API/frontend/realtime impacts, risks, and verification.

## Implement Frontend Screen From Design

Use the frontend UI skill. Keep page thin, use hooks/containers, React Hook Form + Zod for forms, and React Testing Library tests.

## Implement Backend Module

Use the backend standards skill. Add routes, controller, service, repository if useful, Zod schemas, and Supertest route coverage.

## Add Tests

Focus on user-visible behavior, route behavior, service edge cases, and external service mocks.

## Review Architecture

Check package boundaries, dependency direction, SOLID responsibilities, security, and testability.

## Refactor Safely

Keep behavior unchanged, add or preserve tests, avoid unrelated churn, and update docs only when rules change.
