# MVP Scope

## Included

- Single admin authentication
- Dashboard analytics
- WhatsApp templates: list, create, sync status, delete
- Predefined automations seeded in the database
- Automation template, delay, and enabled configuration
- Conversations inbox and 24-hour-window text replies
- Webhook, message, automation, and error logs
- Shopify, Meta/WhatsApp, PWA notification, and admin settings
- Responsive desktop/mobile PWA-ready UI

## Excluded

- Multi-user teams
- SaaS billing
- Multi-store support
- Drag-and-drop automation builder
- Template editing
- Broadcast campaign builder
- AI chatbot
- Audio/video message sending
- Advanced analytics
- Native mobile app
